## 📌 Project Overview

This project presents an interactive data analytics and business intelligence dashboard developed for analyzing the profitability and margin performance of Nassau Candy Distributor.

The application transforms transactional business data into meaningful financial and operational insights by analyzing:

- 📊 Product-level sales performance
- 💰 Gross profit
- 📈 Gross margin
- 📦 Units sold
- 💵 Profit per unit
- 🏢 Division performance
- 💸 Cost structure
- 📈 Profit concentration
- 🏭 Factory performance
- 🌎 Factory geographic footprint
- 🔗 Product–factory relationships

The objective is to provide a clear, interactive, and data-driven view of business performance.

## 🧮 Key Performance Indicators

| KPI | Formula / Description |
|---|---|
| 💰 Gross Margin (%) | Gross Profit ÷ Sales × 100 |
| 📦 Profit per Unit | Gross Profit ÷ Units |
| 📈 Revenue Contribution | Product Sales ÷ Total Sales × 100 |
| 💵 Profit Contribution | Product Profit ÷ Total Profit × 100 |
| 📊 Margin Volatility | Variation of margin over time |

## 🧹 Analytical Methodology

### 1️⃣ Data Cleaning & Validation

The application prepares and validates the data before analysis.

Processing includes:
- Validating sales values
- Validating cost values
- Validating gross profit values
- Checking unit values
- Handling missing values
- Removing invalid records
- Standardizing product labels
- Standardizing division labels
- Checking data consistency

### 2️⃣ Profitability Metric Calculation

For every product, key profitability metrics are calculated.

**Gross Margin**
Gross Margin (%) = Gross Profit / Sales × 100
